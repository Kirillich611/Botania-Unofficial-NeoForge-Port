# Botania 457.1 — Minecraft 1.21.1 / NeoForge

Рабочая совместимая сборка исходников Botania 457 от друга. Загрузчик для проверки: NeoForge 21.1.248; Java 21. Неизменённая копия друга находится в соседней папке `1.21.1_NeoForge_457_КОД_ДРУГА_новая_основа`.

Изменения: сборка с доступными локальными Gradle-зависимостями; восстановление зачарованной почвы, семени разрастания и воздуха Края; старые имена 476 предметов и 329 блоков разрешаются через registry aliases; цвет модели лексикона содержит непрозрачный alpha; поверхность маны использует совместимый с Iris стандартный тип рендера с анимированной текстурой. ExtraBotany 1.9.3 использует API именно этой версии.

Сборка: `gradlew.bat :NeoForge:assemble --offline` (нужны заранее загруженные зависимости). Из рабочего проекта ExtraBotany запускайте `scripts/build-botania457.ps1 -Offline`: он также помещает Botania в локальный Maven-кеш для сборки аддона.

Старые кварцевые блоки в инвентаре требуют внимания: часть их старых ID теперь занята кристаллами. Registry aliases исправляют переименованные ID, но не могут различить такие совпадения. Перед переходом проверяйте копию мира. Оригинальные исходники не изменялись.

Релизы: `C:\Modds\builds\Botania\1.21.1\457.1\`. Рабочий каталог сохраняет своё имя при новых выпусках.
